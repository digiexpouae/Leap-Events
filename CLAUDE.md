# Next.js & Node.js Developer Rules

## Core Commands
- Dev Server: npm run dev
- Production Build: npm run build
- Lint Check: npm run lint
- Run Tests: npm test

## Style & Architecture Guidelines
- Framework: Next.js (App Router), React, Tailwind CSS, TypeScript.
- API Design: Use Node.js native fetch / clean async-await handlers.
- Code Style: Write clean, concise code. Do not output conversational explanations or fluff.
- Modification Rule: Only update code fields explicitly requested. Fix bugs incrementally without global refactors.
